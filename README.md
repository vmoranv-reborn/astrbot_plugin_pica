# AstrBot 哔咔漫画下载器插件

这是一个用于AstrBot的哔咔漫画下载器插件，支持搜索、收藏管理和下载功能。

## 功能特性

- 🔍 搜索漫画（支持关键词和漫画ID）
- 📚 查看收藏夹和排行榜
- 📖 查看漫画详细信息和章节列表
- ⬇️ 下载漫画章节和图片
- 🔄 断点续传（自动跳过已下载内容）
- 🎯 灵活的章节选择（支持范围选择）
- 🌐 代理支持
- ⚙️ 可视化配置管理
- 📁 标准化数据存储

## 安装方法

1. 将插件文件夹放置到AstrBot的插件目录
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

## 配置说明

### 通过管理面板配置

插件支持AstrBot的可视化配置面板，可以配置以下参数：

**登录配置：**
- `account` - 哔咔账号邮箱
- `password` - 哔咔密码

**网络配置：**
- `proxy` - 代理服务器地址（可选）
- `secret_key` - API密钥（可选，默认使用内置密钥）

**下载设置：**
- `concurrency` - 下载并发数（默认5）
- `timeout` - 下载超时时间（默认30秒）
- `retry_count` - 重试次数（默认3）

## 数据存储

插件遵循AstrBot的数据存储规范，所有下载文件和记录都存储在标准数据目录中：

```
data/plugin_data/astrbot_plugin_pica/
├── 漫画标题1/
│   ├── 章节标题1/
│   │   ├── 001.jpg
│   │   ├── 002.jpg
│   │   └── ...
│   └── 章节标题2/
│       └── ...
├── 漫画标题2/
│   └── ...
└── done.txt                  # 已下载记录文件
```

## 使用方法

### 基础命令

```bash
/pica_help                    # 显示帮助信息
/pica_status                  # 查看配置和登录状态
```

### 搜索功能

```bash
/pica_search 关键词           # 搜索漫画
/pica_leaderboard             # 查看排行榜
/pica_favorites [页码]        # 查看收藏夹
```

### 信息查看

```bash
/pica_info <漫画ID>           # 查看漫画详细信息
/pica_episodes <漫画ID>       # 查看漫画章节列表
```

### 下载功能

```bash
# 下载所有章节
/pica_download <漫画ID>

# 下载指定章节
/pica_download <漫画ID> 1,3,5-10

# 下载单个章节
/pica_download <漫画ID> 1
```

### 章节选择格式

- `all` 或 `全部` - 下载所有章节
- `1,3,5` - 下载第1、3、5章
- `1-10` - 下载第1到10章
- `1,3,5-10,15` - 混合格式

## 工作流程

1. **首次配置**：在AstrBot管理面板中配置账号密码
2. **自动登录**：插件启动时自动使用配置的账号登录
3. **使用功能**：登录成功后即可使用所有功能
4. **状态查看**：使用 `/pica_status` 查看当前状态

## 断点续传

插件会自动记录已下载的章节和图片，再次运行时会跳过已下载的内容：

- `done.txt` 文件记录已下载的章节
- 检查本地文件是否存在来跳过已下载的图片

## 注意事项

1. **网络环境**：哔咔漫画需要特定的网络环境才能访问
2. **账号安全**：请妥善保管账号密码，建议使用专用小号
3. **存储空间**：漫画图片占用空间较大，请确保有足够的存储空间
4. **下载限制**：请合理控制下载频率，避免对服务器造成过大压力
5. **版权声明**：请遵守相关法律法规，仅供个人学习使用

## 故障排查

### 插件未登录
- 检查管理面板中是否配置了账号密码
- 确认账号密码是否正确
- 检查网络环境是否能访问哔咔

### 搜索无结果
- 确认插件已登录（使用 `/pica_status` 查看）
- 确认搜索关键词是否正确
- 检查网络连接

### 下载失败
- 检查存储空间是否充足
- 确认目录权限是否正确
- 尝试降低并发数
- 检查代理设置
